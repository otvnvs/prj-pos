# VueJS: Point of Sale

A modular, mobile-first responsive Point of Sale (POS) application built using Vue 3 (Composition API) and Vite. This application is optimized for touch interaction environments and supports real-time catalog filtering, focus highlights, automated smooth scrolling, and an interactive transaction ledger.

Live Demo: [https://otvnvs.github.io/prj-pos/](https://otvnvs.github.io/prj-pos/)

## Features

- **Mobile-First Responsive Interface:** Adapts fluidly from a dual-pane layout on desktop screens to a thumb-accessible drawer and navigation system on mobile screens.
- **Dynamic Context Search & Dropdown:** Typing filters the inventory into a floating list. Selecting an item applies a gray-out mask to non-matching elements and focuses the chosen card.
- **Automated View Scrolling:** The catalog leverages template references to automatically center and highlight chosen elements, bypassing layout cut-offs on small viewports.
- **Local State Routing Matrix:** Swaps page views (Home, POS, Transactions, About) instantaneously without requiring heavy external routing dependency files.
- **Transactional Memory Ledger:** Keeps a historical stack of processed checkouts, generating unique reference IDs, item counts, and timestamps per receipt.
- **Hardware Scanner Ready:** Includes an explicit form layer inside the input wrapper to intercept emulated keyboard Enter parameters generated by physical USB/Bluetooth laser scanners.

## Project Architecture

```text

├── src/
│   ├── components/
│   │   ├── AboutScreen.vue    # System information configuration layout

│   │
│   ├── App.vue                # Main application mounting context
│   ├── main.js                # Instantiates application lifecycle instances
│   └── style.css              # Global custom utility layouts and design variables
│
├── index.html                 # Main web viewport access module template
├── package.json               # Run dependencies and compile control script wrappers

```

## Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org) installed on your machine.

### Installation

1. Clone the repository to your workspace:
   ```bash
   git clone https://github.com
   cd prj-pos
   ```

2. Install the necessary project dependency packages:
   ```bash
   npm install
   ```

### Development Run

Launch the instant hot-reloading local development server:
```bash
npm run dev
```
Open your browser and navigate to the link provided in your terminal shell (typically `http://localhost:5173/`).

### Production Compilation

To bundle and optimize application assets for web-server hosting environments:
```bash
npm run build
```
This script compiles production-ready outputs into a local `./dist` target directory.

## Production Configuration Note

The system uses a relative path baseline configuration (`base: './'`) inside `vite.config.js`. This guarantees that your compiled bundle successfully resolves its nested script and style links when served inside a shared repository directory structure like GitHub Pages (`/prj-pos/`).
